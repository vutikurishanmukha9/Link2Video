# Link Downloader Pro

# GLOBAL DESIGN DIRECTIVE
# PROJECT: PREMIUM MULTI-PLATFORM MEDIA DOWNLOADER
# PRIORITY: VISUAL QUALITY > DECORATION
# DESIGN MODE: LIGHT/DARK HYBRID
# AUTHENTICATION: NONE
# FRONTEND ONLY FOR NOW

You are designing a premium, production-quality frontend for a
multi-platform media downloader.

The product allows a user to paste a public social-media post URL
and retrieve available photos/videos from supported platforms.

Supported platforms:

• Instagram
• X / Twitter
• Facebook
• LinkedIn
• Reddit


The frontend must feel like a serious modern software product.

It must NOT look like:
• an AI-generated SaaS landing page
• a generic downloader website
• a template from a component library
• a crypto dashboard
• an AI startup landing page
• a "10x productivity" website
• a gradient-heavy startup website
• a Dribbble concept that cannot actually be used

The design must feel intentional, engineered, restrained and premium.
